# caching-lab — правила для ассистента

- Публичный репозиторий. Никаких корпоративных имён: сервисов, таблиц, пакетов, тикетов и названий компаний из рабочих проектов. Список запрещённых слов лежит в `.git/info/forbidden-words` и проверяется хуками `pre-commit` и `commit-msg`.
- Стек: Java 25, Spring Boot 4.1, WebFlux, R2DBC через `DatabaseClient`, Reactor, Caffeine. Без JPA.
- Каждый приём кэширования — отдельный сервис в `scenario` и отдельный тест `ScenarioN…Test`. Главная проверка — `ProductSource.callCount()`. У каждого сценария — описание в `docs/scenarios/NN-….md` и файл ручной проверки `http/NN-….http`; при изменении сценария обновлять все три.
- Время в тестах двигает `ManualTicker`, без `sleep`.
- Стиль: многострочные комментарии одним блоком `/* */`, фигурные скобки у тел `if`/`for`/`while`, говорящие имена.
- Ветка `main`. Коммит и пуш — по окончании задачи, `git add` по именам файлов, перед пушем `git fetch`.
